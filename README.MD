# 《AbstrO》

**从三张折叠桌到天空塔** —— 一款网页文字放置游戏。唯一目标：让公司市值成为**世界第一**。

一局 = 8 章 = 40 年（2026–2066）≈ **5.3 小时**。

---

## 玩法

- **一个循环**：接单赚钱 → 投五条线 → 市值涨 → 推下一章。推进只有一个闸门：`市值 ≥ 本章门槛`。
- **三个资源**：**现金**（唯一可消费）· **现金储备**（现金的 80%，买不动的那笔钱）· **市值**（得分）。
- **五条投资线**：研发 / 营销 / 招聘 / 算力 / 渠道，共用一条成本曲线 ——「买等级最低的」自动维持均衡，偏科会指数级变慢。
- **一年一个决策点**：主界面长一张待决卡片，不弹窗；第 7 章起交给自动化。
- **订单是加速器**：每 9 个游戏月来一单（一局约 53 单），只给现金、不给长期乘数。
- **八章一条路**：出租屋 → 车库 → 写字楼 → 资本局 → 海外分部 → 全球总部 → 交易所 → 天空塔。
- **公司名随规模缩短**：`Abstract Studio → Abstract Labs → Abstract Tech → Abstra → AbstrO`，每次换幕落一条日志。
- **登顶之后还有回味期**：你不能再操作，但公司继续长大、榜单继续走 —— 还能再看一会儿。

年份是**进度钟**：玩得快时间走得快；卡住时，时间和世界榜一起冻结。

## 快速开始

```bash
npm install
npm run dev          # http://localhost:5173
```

出包与部署：

```bash
npm run build        # 产物在 dist/
npm run preview      # 本地预览产物
```

产物用 `base: './'` + 不带哈希的固定文件名，**直传任意目录都能跑**（含子目录）；缓存靠构建时注入的 `?v=<构建时间>`，不用手动清。
唯一的服务器侧要求：**`/studio` 要 301 到 `/studio/`**，否则不带斜杠的地址会白屏。

## 技术栈

纯前端 **ES Module + Vite** —— 无框架、无后端、**零运行时依赖**（`devDependencies` 只有 `vite` + `playwright`）。

## 目录结构

```
src/core/   11 个   引擎与数据（content.js 是唯一数据源）
src/ui/      4 个   渲染 / 事件绑定 / 音效 / 样式
src/main.js         唯一接线处
tools/      12 个   九条开发闸门的实现
```

## 开发闸门

改任何数字之后，这九条必须全绿。所有脚本恒 `exit 0`，结论只读末尾的 `BRIEF {...}`：

```bash
npm run tune      # 曲线幂等 + 双旋钮校准
npm run check     # 主动路径：3~6h、终局登顶（--idle 为挂机路径）
npm run robust    # 极差与手速边界
npm run probe     # 100 条流程探针
npm run click     # 77 步：从渲染出的 HTML 一路点到结局
npm run build     # 产物可上传（含 5 帧启动烟测）
npm run shots     # 真 Chromium 截图：溢出 / 日志折行 / JS 错误即红
npm run dead      # 0 孤立模块、0 零引用导出
```

纪律：改 `content.js` 任何数字 ⇒ 必须重跑 `tune` + `check` + `robust`。
