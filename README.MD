# 《Abstract Studio》创业模拟器

> 网页文字**放置游戏**。唯一目标：让公司市值成为**世界第一**。
> 一局 = 8 章 = 40 年（2026–2066）≈ **5.3 小时**。

---

## 一、怎么打开

```bash
npm install
npm run dev          # 本地开发，默认 http://localhost:5173
```

出包上线：

```bash
npm run build        # 产物在 dist/，可直接 SFTP 上传（支持子目录，见下）
npm run preview      # 本地预览构建产物
```

- 构建用 `base: './'` + **不带哈希的固定文件名**：产物用**相对路径**引用资源，所以**直传任意目录**（含 `https://example.com/my-game/`）都能跑，也方便覆盖上传。
- 缓存靠 `tools/postbuild.mjs` 给资源 URL 加 `?v=<构建时间>`，不需要手动清缓存。
- ⚠️ 只有一条服务器侧要求：**`/studio` 要 301 到 `/studio/`**，否则不带斜杠的地址会白屏。

## 二、怎么玩

### 三个资源

| 资源 | 说明 |
|---|---|
| **现金** | 唯一可消费资源。账上的钱永远有 `20%` 能动 —— 储备按**现金的比例**走，「现金少了储备也跟着少」是恒等式 |
| **现金储备** | **现金** × 80%（`RESERVE_FRAC = 0.80`），**账上留存的、买不了东西的那笔钱**。可动用现金 = 现金 − 储备金。HUD 上与「现金」**同占一格**（大字 = 现金总额、副行 = `可动用 ¥X ｜ 储备 ¥Y`），两者同步涨落 |
| **市值** | 进度与得分 = 年营收 × 市盈率（纯派生，不入存档） |

### 五条投资线（自动是打折版，手动是满配）

五条线**完全对称**：共用 `cost(n)`、共用同一个 `g = 1.13^(1/5) ≈ 1.0247`。
共用一个成本曲线 ⇒「买等级最低的」自动维持均衡 —— 偏科会按 `1.1019^L` 指数级变慢，「五条都要投」是公式强制的。

| 页 | 投资线 | 变量 |
|---|---|---|
| **创始人** | 投研发·老钟 / 投营销·小严 / 投招聘·小朱 | 产品力 / 赛道份额 / 团队效率 |
| **公司** | 算力 / 渠道 | 算力、渠道（名字按章长大：借来的显卡 → … → 千兆瓦级算力集群） |

- **自动购买默认开启、无开关**：每 tick 检查可动用现金，够 `K` 份成本就买下**等级最低**的那条线（留一份钱给玩家，否则手动按钮永远点不动）。
  `K` **分两档**：**融资前**（还没拿到任何一轮钱）是 `6` —— 窗口大、玩家一动手就把自动挤出购买周期，**这几章实际上是你自己点的**；**天使轮到账后**回到 `2`。
- **手动点击**：同一个 `purchase()`、同一条可动用现金闸门，一次买 **2 级**，但**只付 `MANUAL_PAY = 1.565` 级的钱**（第一级原价 + 第二级半价）。
  跟着购买节律点，全程 `3.13h`（挂机 `5.36h`）⇒ 快 **1.71×**；而全手动也不许快过 `3h`（手动是更优策略，不是跳过游戏）。
  **手速不是主要变量**（瓶颈是钱不是手，每 1 秒点与每 20 秒点只差 `1.077×`，判据 `≤1.5×`）。

### 年度决策（全作唯一的打断点）

每年 **1 条**待决事件，主界面「公司」页长一张待决卡片（数量角标 + 第一条的选项），**不弹窗**；
待决 `> 0` 时**「公司」页签亮 `.hot`**（复用订单页签同一套视觉）—— 不切过去也看得见有事在等。
选项带效果数字（`现金 +3.0% 年营收 · 产品力 ×1.015`）。
每个选项只影响五个变量：`cash / prod / share / team / pe`。
- **积压上限 3 条**：第 4 条起按默认（保守）选项自动结算，年度报告里记一行。
- **第 7 章起全自动**：公司已经大到三个人管不过来，年度事件不再交给玩家。

### 订单（「订单」页）

每 **9 个游戏月**生成 1 条（一局约 53 单），在手最多 **3** 条。
报酬 = 当前年营收 × 档位（`tier.payEq / 500`）× 客户类别 `kind.pay` × 形态 `form.pay`，三层系数全部由 `uid` 现算。
- 六个档位（`小活 15s` → `战略级工程 80s`）**各配一份真实公司名单**，一次抽三样：**等级 / 客户类别 / 形态**。
  等级决定甲方从哪份名单里抽（小档便利店 / 连锁，大档小米 / 台积电）；客户类别（连锁零售 / 上市公司 / 超级巨头 / 国际大厂）
  与形态（一次性的活 / 订阅 / 出租算力）只进数值。**文案里只写「公司名称 + 形态」**，等级与客户类别不出现在字样上。
  单子上还跟一句交付内容。
- 点「交付」= 准时 `×1.0`；到期自动交付 = `×0.9`。
- **开局第一条单固定第 2 档**（`系统对接`）—— 唯一的等级特例：不这样，第 0 条单（最小档）
  连一级线都买不起，开局第一件事等于白做。
- 订单**只给现金，不给任何长期乘数** —— 它是加速器，不接管主循环。

### 八个阶段

出租屋 → 车库 → 写字楼 → 资本局 → 海外分部 → 全球总部 → 交易所 → 天空塔。

推进只有一个机械闸门：`市值 ≥ 本章门槛`。年份是**进度钟**：玩得快时间走得快，卡住时时间和世界榜一起冻结。
第 7 章完成 **IPO 敲钟**（上市后才进世界榜、公司改名 `Abstract Inc`），第 8 章**登顶世界第一** = 唯一结局。
登顶后**时间与全部计算冻结**，只剩回看。

### 离线与倍速

- 离线上限 **8 小时**；等效游戏时间 = 真实离线秒 × `0.15`（封顶约全程 23%）—— 睡一觉不会覆盖全程进度。
- 回来只给**一份年度报告**。
- 倍速 `1× / 4× / 8×`；速度按钮 + ⚙ 设置常驻页头（**页头恒一行**）。音效可在 ⚙ 里开关（默认开）。
- 登顶后 HUD 上方会多出一条可点的「**退休**」通栏横条（重看结局）—— **只在登顶之后出现**，页头里没有它。

### 界面

四个页签：**创始人**（三条投资线）· **公司**（两条资产线 + 待决卡片）· **订单** · **市值榜**（前 20 名，玩家上市后进榜、名次 >20 时钉在底部单列）。

页头**恒一行**：左边公司名 + 副行（日期 · 章节），右边只有倍速 / ⚙。
HUD 四格 **2×2**：现金（副行 = 可动用 / 储备）/ 市值（年营收 / **环比 ±x.x%**）/ 净利率＋世界排名（PE / **净利**、上市状态 / **`距天使轮 5年` 或名次环比**）/ 本阶段目标（达成后文字套方框、标题行右端写「完成」，**不打钩**）。日志固定底栏。
**四格恒 4 行、等高、不随数字位数变**（格高锁死 `90px`）；半格可用宽度只有 73px，所以那里只写整数、轮次名不带空格（`距Pre-IPO 7年`，不是 `距 Pre-IPO 7 年`）。
世界格的名次按**档位换色**（`#1` 金 / 前三 青 / 前十 绿 / 已入榜 正文 / `>100` 与未上市 压暗），**只换色相、一个字都不加** —— 那半格里 `#100` 已经占 30px。
登顶后 HUD **上方**多一条「退休」通栏横条（点开重看结局）—— 它是旧版那条 `已登顶 · 时间冻结` 提示的替身，
**同一个位置、同一个条件**（`s.ending` 才出现），文字提示已删除。

市值榜是**会呼吸的**：100 家真实公司逐月演化，上面叠了三层周期 —— **行业轮动**（每个行业 8 年一轮，名次真的会换位）、
**泡沫周期**（全市场 12 年一轮，把榜单数字整体吹起或抽干；你的市值不在这个乘数里，所以泡沫起来时你掉名次）、
**黑天鹅**（个股每月 0.5% 概率 ±15~35%）。全部由 `(月份, 公司)` 的哈希算出，**无状态** ⇒ 同一份存档永远一致。
三层周期都会**写进日志**（`【大盘】/【轮动】/【黑天鹅】`）—— 名次是结果，这几行是原因。
每类播报的句子都从各自的文案池里**按「本局第几条」轮取**（黑天鹅涨 / 跌各 12 条归因、AI 回撤 5、泡沫 7、轮动 6），
池子 ≥ 一局条数 ⇒ **一局 33 条播报每句只出现一次**（改前最坏一句撞 6 次）。
你上市后的那一行会**加框 + 呼吸高亮**，一眼就能在 20 行里找到自己。
每行右边多一列**环比**（对比上个月的涨跌 %，绿涨红跌；新入场与基本没动的留空）；
**点任意一行**在下面展开公司详情（`行业 消费 / 零售 · 美国 · 2026 年入场`），同值再点收起；
榜头那句「当前最热：X」与日志里的周期播报同源。

每次**推幕**（进入新一章）写一条 `2030年【车库】借来的车库，租金按天算。`：年份 + 地名 + 一句专属开场，
八章八条各不相同（文案在 `ACTS[].open`，不再是八幕共用同一模板）。
⚠️ **硬约束：整行必须在手机日志栏一行放下**（可用宽 366px，八条一律 ≤ 52 单位），`probe` 守字符预算、`shots` 用真 Chromium 量像素。

订单一条占**两行**（第一行甲方 + 报酬、第二行交付内容 + 剩余月数 + 交付按钮），带分割线；右上角是「已完成 N 项」。
所有数字都写了**单位**：`¥…/秒`（上万自动换 `¥…/年`）、`PE … 倍`、市值榜 `万亿美元`（创始人年龄不带单位）。

## 三、开发者部分

### 技术栈

纯前端 **ES Module + Vite**，**无框架、无后端、零运行时依赖**（`devDependencies` 只有 `vite` + `playwright`）。

```
src/core/   11 个   content  economy  engine  state  save
                   format   world    world-data  endings  finance  orders
src/ui/      4 个   render   bind     audio    style.css
src/main.js        唯一接线处
tools/      12 个   九条闸门的实现（不新写引擎，全部复用 / 扩展旧版）
```

- `content.js` 是**唯一数据源**：常数 → 八章 → 五条线 → 创始人叙事 → 年度决策事件。
- 经济模型只有一个乘积，**没有加法桶、没有隐藏乘数层、没有绝对额固定支出**（绝对额支出是旧版「不可恢复死锁」的全部来源）。

### 九条闸门

改任何数字之后，这九条必须全绿。**所有脚本恒 `exit 0`**，结论只读末尾的 `BRIEF {...}`。

| 命令 | 判据 |
|---|---|
| `npm run tune` | 幂等（起点即达标 ⇒ 一个字节都不写盘）；双旋钮（`LINE_COST0` 时间 + `ACTS[].mcap` 形状） |
| `npm run check` | 主动路径：`bad 0`、合计 ∈ `[3,6]h`、终局登顶 |
| `npm run check -- --idle` | 挂机路径：`bad 0`、合计 ∈ `[3,18]h`、终局登顶 |
| `npm run robust` | A 档极差 ≤ `2.0×`、D 档 ≤ `3.0×`；手动分量 ≥ `1.5×`；全手动 ≥ `3h`；手速 ≤ `1.5×` |
| `npm run click` | 76/76：从渲染出的 HTML 找按钮 → 走事件委托 → 走到结局（含 ⚙ 里音效开关、开局无「退休」按钮、登顶后「退休」横条在 HUD 上方并点得开结局、市值榜每行点开 / 收起详情） |
| `npm run probe` | 84/84：流程探针全绿（含经济模型六条不变式、首帧不黑屏、四个弹窗真清空、「退休」横条只在登顶后出现、周期日志幂等、四段低谷可见、周期两端锚点不被污染、终局现金/年营收 ∈ `[0.20, 0.32]`、市值榜环比列 / 公司详情 / HUD 三格第三行 / 环比基准只在跨月换一次、世界格名次五档分色、八章推幕行八条各不相同且 ≤ 52 单位） |
| `npm run build` | 产物可上传（含启动 5 帧烟测；`index.html` 不含任何 HTML 注释） |
| `npm run shots` | 16 张截图（4 页签 × 2 端点 × 2 阶段）：无溢出、无 JS 错误、无残留遮罩、**推幕行在 390px 上必须一行放得下** |
| `npm run dead` | 0 孤立模块、0 零引用导出 |

**纪律**：改 `content.js` 任何数字 ⇒ 必须重跑 `tune` + `check` + `robust`；
**新的接线必须同步抄进 `click-sim` / `probes`，漏抄按缺陷处理**。
